Como manter seu link no GitHub Pages sem erro 404

  1. Baixe este arquivo e garanta que o nome seja exatamente index.html (todo em minúsculo, sem (1) no nome).
  2. No seu repositório comercial-crvportasejanelas no GitHub, clique em Add file → Upload files e envie o index.html diretamente na raiz (não dentro de pasta).
  3. Clique em Commit changes e aguarde ~40 segundos (bolinha verde na aba Actions).
  4. Suas edições ficam salvas automaticamente no navegador (localStorage) no endereço fixo do GitHub Pages.
